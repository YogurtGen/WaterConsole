# WaterConsole Core 0.4.2

- Remove the extra ••• overlay from game covers. Right-click or focus a card and press Shift+F10/Menu to edit, open Studio or delete a user-added entry. README and the in-app guide explain the workflow.
- Fix custom banners being constrained to a smaller 16:9 box inside the Home panel. Fill now covers the entire panel; Fit still keeps the full image with possible space. New banners default to Fill. Existing saved Fit preferences stay intact.

Library scrolling keeps its hidden scrollbar and phone navigation. Local library/controller records and original images are preserved. Commercial games and publisher assets are not bundled with Core.

Button images: **Remove image** and **Remove pressed image** clear their own image/crop references. Removing the last image returns the button to text; Undo can restore it. Images and their crop preview follow circle, square, triangle, rounded-rectangle and pill shapes. **Button image fit** selects Fill/cover or Fit/proportional display. Original files remain unchanged.

Canvas backgrounds also support **Remove image**; mode/player overrides use **Clear background**. Removing a background restores its color, and Undo can restore the image.
