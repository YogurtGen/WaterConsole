# WaterConsole Core 0.4.4

Switching the phone controller between Menu, Standard, Fight and Race now preserves the landscape lock instead of briefly unlocking to portrait and locking again. Input still resets when the mode changes.

Entering a game or Studio preview requests landscape after fullscreen is entered. Returning Home releases the lock. Exiting and re-entering fullscreen can retry rotation if the browser rejected it; unsupported browsers keep the rotate hint and responsive controller.

Game bindings, saved layouts, images and vibration are unchanged. The browser regression checks lock/unlock calls and fullscreen across all four phones; physical rotation remains a real-device check.

The launch setup now explains that **Only connect to an already running game** deliberately does not open the executable. Leave it off to launch from Start game, or select the current window when using an external launcher.

- **Choose running game** searches open game/application windows and fills the original executable automatically. Save before connecting; picking a window does not start input.
- **Auto** launches recognized Steam installations through the original Steam client, waits for the real game window, and reuses matching open windows. **Direct executable** remains available. Connect-only mode now explains when it intentionally skips launching.
- Window titles, executable paths and launcher settings remain PC-only. Native game bindings and installed system drivers are unchanged.
