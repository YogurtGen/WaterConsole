# WaterConsole Core 0.5.2

Added games now use the same console session layout as built-in games: large artwork on the left, status and phone modes in the right panel, and player cards underneath.

- Uses the game's saved banner, then its cover, with an original placeholder when neither is available. Artwork stays visible during launch and errors.
- Shows Starting, Game in focus, Input paused, Needs attention and Closing states accurately. Focus, Stop, input recovery and launcher ownership keep their existing behavior.
- Highlights the active controller mode. Custom mode names wrap inside the panel; switching layouts does not claim to change the game scene.
- Player cards follow the game's supported player count, show reconnect/setup status and provide pairing links for empty slots.
- The layout adapts to smaller windows and long game/player names.

Checked with original isolated fixtures: eight configured-session UI checks on private/Core, including banner loading/fallbacks, command contracts, all session states, one/two/four players, eight modes and small-window containment. Typecheck, production builds, shared/server tests and LAN regressions pass. No commercial game or driver is launched/installed by these checks. Existing artwork, controller layouts and bindings are preserved.

The packaged Core application also passes the same eight session checks. Existing installed-library artwork was checked privately without launching a game; physical-phone and real-game compatibility are outside this presentation change.
