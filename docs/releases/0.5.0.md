# WaterConsole Core 0.5.0

Add installed Steam and Epic games from the PC editor, and design controllers using the same frame and renderer as the phone.

- **Scan Steam & Epic:** select a local installation and fill an editable setup with title, description, tags, cover and banner. Local files come first; missing official metadata/artwork download when online and stay cached. Import does not launch or save a game.
- **Comfortable phone fit:** left/center/right anchors use wide screens without collecting controls in the middle. Shape and relative sizes stay proportional; grouped controls stay together. Exact-composition and full-canvas alternatives remain available.
- **Shared preview:** Studio edits the actual phone canvas by default, including direct selection, drag and resize; it reserves the same header/safe-area space and matches the phone renderer. The compact header follows the existing WaterConsole interface.
- **Console models:** add soft action/primary/face/shoulder controls, analog discs and a symmetric petal D-pad. Cross and disc alternatives remain editable. No existing bindings are replaced.
- **Original launchers:** Auto recognizes matching local Steam/Epic manifests and uses their original clients, while Direct and existing-window attachment remain available.
- **Contributor guidance:** AGENTS.md documents the established phone visual baseline, shared components, layout checks and optional source/AI adapters.

Only Controller Lab ships. Imported commercial games, their artwork, executable paths and user libraries are not in the public source/app. Player counts, input compatibility and offline operation remain unverified until the owner tests them.

Validation: 111 public unit checks; editor UI, four-browser controller/recovery checks, 14 LAN end-to-end checks; six Studio/phone geometry/direct-edit/model checks at 780×360, 844×390, 915×412 and portrait. Local store discovery and official metadata/art downloads were checked on this PC, then the same cache was checked with fetch disabled. No commercial game was launched for this update. Physical-phone comfort, vibration and rotation remain device checks.

The installed-game picker uses non-shrinking rows with separate title, store/status and location lines. Long text truncates within its own row; search, store filters, launch-file review and the footer were checked at four desktop sizes down to800×600.

Installed-only scan checks local installation state and non-empty executable files, and rechecks the selected installation before import. Owned-but-uninstalled titles are not fetched from a cloud account.
