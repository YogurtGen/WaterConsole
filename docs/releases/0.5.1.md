# WaterConsole Core 0.5.1

Controller Studio now shares workspace space through draggable dividers, and selected controls can be copied or duplicated with familiar shortcuts.

- Resize the Controls pane, Inspector and bottom tools; neighboring canvas space updates immediately. Sizes persist on the PC.
- Double-click a divider to restore one pane, or use Reset layout for all panes. Controller positions, artwork and bindings stay unchanged. Keyboard resizing is also available.
- Refreshed Menu, Standard, Fight and Race starting templates use soft controls, petal directions and stable hand anchors. Primary actions inherit player colors; Race keeps editable physical RT/B bindings and the linked RT+B hold. Saved layouts are not migrated.
- Console-model cards adapt to narrow/wide panes; illustrations and labels stay inside their cards.
- Ctrl+C / Ctrl+V copies controls across modes and game setups in the current app session. Ctrl+D duplicates immediately; multi-select and Undo/Redo work. Text fields retain normal text shortcuts.
- Pasted controls preserve per-player keyboard/gamepad bindings, linked actions and visual settings, with independent identities and bounded group positioning. Limits are checked before any edit.

Validation uses original isolated fixtures: pane resize/persistence/reset, narrow-window containment, clipboard shortcuts, cross-mode bindings, Studio/phone geometry and existing editor/LAN regressions. No commercial game or system driver is launched/installed for these changes. Physical-phone comfort remains a separate check.

Checked on Windows x64: typecheck and production builds; 124 shared/server tests; 14 LAN flow checks; 9 four-controller input checks; 6 Studio/phone layout checks covering all four templates at four viewport sizes; and packaged-app workspace (9) and editor (20) checks. Physical-phone ergonomics/fullscreen/vibration and clean-machine installation are not claimed by these browser/fixture checks.
