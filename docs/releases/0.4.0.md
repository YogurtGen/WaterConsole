# WaterConsole Core 0.4.0

A controller usability update for the local game builder.

- Optional visual Xbox/PlayStation/full keyboard binding editor, per-player ownership, linked holds, shared-input colors and usage tooltips. Contained hotspots and leader-line labels keep the diagrams readable. Advanced fields remain available.
- New presets use physical input names instead of assuming acceleration/brake/drift actions. Existing profiles keep their mappings.
- Fix icon-catalog scrolling that could blank the editor; tool errors keep the parent draft accessible.
- Fix live color/HEX Enter updates, inherited swatches and scope-specific color fields. Background images preview on the controller canvas; button images remain independent.
- Personal phone layout adjustment: drag, proportional resize, Done/Cancel/Reset, local storage and portrait/landscape records. No binding changes and no input during editing.
- Gameplay landscape request and a clear fallback when fullscreen/orientation lock is unavailable.
- Expanded keyboard allowlist for punctuation, navigation, numpad and left/right modifiers. System shortcuts remain filtered.

Core contains Controller Lab and the generic game builder. It does not bundle commercial games, game-specific adapters or publisher artwork. Existing developer/source integrations remain supported.

Install the new setup over your existing Core installation. Local games and data stay in the separate data folder. Open an existing controller to edit it; presets only replace a mode when explicitly selected. New directional-key mappings require 0.4.0 or later.

Browser/API fixture tests cannot prove physical vibration, real Android orientation behavior, Wi-Fi performance or compatibility with a particular game. See the current validation report and troubleshooting guide.
