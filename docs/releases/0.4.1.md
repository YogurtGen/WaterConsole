# WaterConsole Core 0.4.1

- Browse long game rows with the mouse wheel, trackpad, swipe or visible carousel arrows, with the scrollbar hidden. Navigator-phone D-pad selection automatically brings the chosen card into view.
- Right-click, Shift+F10 or the card's ••• button opens Edit game, Controller Studio and Delete from library for user-added entries. Deletion requires a clear confirmation and leaves the actual game files in place. Built-in/source adapters retain their source-managed configuration.
- A compact contextual Color & fill panel replaces the long color-field stack. Select a control, choose Fill/Text/Icon, and switch Normal/While pressed; one picker opens at a time. Canvas background is always available. More colors and Role & player themes retain advanced settings.
- Controller Studio now separates Text color / Icon color and Pressed text color / Pressed icon color, with live PC and phone preview. Old themes keep their previous appearance. Uploaded images retain their original colors.

Installer and portable Core still contain Controller Lab and the generic game builder, without commercial games or game-specific adapters. Update your existing Core installation; local library and controller data stay in their separate data folder. Refresh paired phone pages after restarting the PC app.

Validation: 92 Core unit checks; focused GUI checks cover wheel/arrow browsing, approved-phone scrolling, context-menu keyboard access, cancelled/confirmed deletion, and independent text/icon colors reaching a browser controller while held/released. Browser tests do not prove physical-phone comfort, vibration or a specific game's compatibility.
