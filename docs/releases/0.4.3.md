# WaterConsole Core 0.4.3

Game controllers now request landscape as soon as a game opens, including its Menu mode. Studio phone previews follow the same rule. Switching to Standard, Fight or Race is no longer required to rotate the controller. Returning to the WaterConsole Home releases the orientation lock.

Tap **Enter controller** or the phone's fullscreen icon first. If fullscreen is exited, tap the icon to re-enter it and request landscape again. Browsers that cannot lock orientation retain the rotate/fullscreen hint and a usable responsive controller.

This patch preserves game bindings, player layouts, artwork, input recovery and vibration. No games or drivers are bundled or installed. Browser tests verify the request and fallback logic; physical-device rotation still depends on browser support.
